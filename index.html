전투 시스템 — 메커니즘과 상성

러닝 패턴 문법 수치화 · 자동 전투 엔진 역공학 · 병종 상성 삼각

⊕ 보완 병합 · 5개 패턴 파라미터 공식 · 라운드별 처리 5단계 · 타겟 선택 알고리즘
핵심 통찰: 전투 결과는 전투 시작 전에 결정된다. 5단계 라운드 처리(전처리→이니셔티브→타겟 선택→피해 계산→상태 적용)의 각 단계가 고유한 과금 동기와 직결된다. 항공=이니셔티브 우위 구매, 혼합편제=타겟 분산을 위한 다종 병사 과금, 방어 수확 체감=균형 투자(= 여러 과금 채널 동시 소모).

1단계이니셔티브 — Speed 내림차순 정렬 → 항공이 선제 공격

4단계상태 적용 — 탈락 처리 · 영웅 쿨다운 · 종료 조건 체크

방어 감소율 = DEF / (DEF + 1500) — DEF 1500 시 50%, DEF 3000 시 67%

월드맵 및 대외 콘텐츠

핵심 통찰: 5개 맵 레이어(지형→자원→몬스터→거점→소셜) 중첩이 집단 책임감을 개인 과금으로 전환하는 구조를 만든다. 수도 보상 격차(수성 동맹 12,000 다이아 vs 0)는 강제 과금이 아닌 "자발적" 과금 유도 설계다.

4. 거점중립 요새, 수도, 동맹 영지병사 전투력, 치료
5. 소셜타 플레이어 기지, 공격 로그사회적 압박 → 과금

서버 생애주기 및 신규 서버 설계

탄생→성장→패권→침체→붕괴 5단계 · 이민 비용 구조 · 병합 수익화

핵심 통찰: 서버는 소모품으로 설계된다. 2단계(성장·경쟁)가 전체 생애주기 중 과금 강도 최고 — 모든 이벤트 개입이 경쟁 소멸 시점을 최대한 늦추는 방향이다. 이민 HQ 20+ 비용 차단이 고과금 플레이어 잔류 장치로 기능한다.
